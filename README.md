# Bonfires to Map

Shows the Bonfires you have discovered as JourneyMap waypoints.

The Bonfires registry and each player's discovery records are read on the
server and sent to the client, so the mod works in single-player, LAN, and
dedicated-server worlds. Only bonfires you have already discovered are sent.
Removing a bonfire or renaming it is reflected in JourneyMap.

## Requirements

- Minecraft 1.21.1 with NeoForge 21.1.x
- [Bonfires](https://modrinth.com/mod/bonfires) 1.2.x on both sides
- [JourneyMap](https://modrinth.com/mod/journeymap) on the client to display waypoints

JourneyMap is optional for loading the mod. Without it, discovered bonfires
are still synced but no waypoints are created.
